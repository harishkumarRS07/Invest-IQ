## Signal Generation Logic (Current)

```python
# Only using Transformer prediction
predicted_next_day_price = transformer_model(features)
pct_change = (predicted_price - current_price) / current_price

# Simple thresholds
if pct_change >= +0.5%:
    signal = "BUY"        → Confidence: 55-95%
elif pct_change <= -0.5%:
    signal = "SELL"       → Confidence: 55-95%
else:
    signal = "HOLD"       → Confidence: 55-95%
```

**Key Point**: Signal is 100% based on Transformer price prediction, NOT ensemble.

## Why Only Transformer Now?

1. **Simplicity**: One model is easier to maintain
2. **Performance**: Transformer shows good 62% directional accuracy
3. **Stability**: Less overfitting with single model
4. **Speed**: Faster inference (one model load vs three)

```python
import pickle
from backend.models.lstm_attention_model import LSTMAttentionModel
import xgboost as xgb

class PredictorEnsemble:
    def _load_models(self, ticker: str):
        # Load Transformer
        self.transformer = TimeSeriesTransformer(...).load(...)
        
        # Load LSTM
        self.lstm = LSTMAttentionModel(...).load(...)
        
        # Load XGBoost
        xgb_path = os.path.join(settings.MODEL_DIR, f"xgboost_fusion_{ticker}.pkl")
        self.xgboost = pickle.load(open(xgb_path, 'rb'))
    
    def predict_ensemble(self, features):
        # Get predictions from all models
        transformer_signal, transformer_conf = self.transformer_predict(features)
        lstm_signal, lstm_conf = self.lstm_predict(features)
        xgb_signal, xgb_conf = self.xgboost_predict(features)
        
        # Vote or average
        signals = [transformer_signal, lstm_signal, xgb_signal]
        confidences = [transformer_conf, lstm_conf, xgb_conf]
        
        final_signal = max(set(signals), key=signals.count)  # Majority vote
        final_confidence = np.mean(confidences)
        
        return final_signal, final_confidence
```
